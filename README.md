# 🎵 Split Sheet Calculator

### Music Publishing & Creative Contribution Calculator

The **Split Sheet Calculator** is a web-based tool designed specifically for the music and creative industry to help **artists, producers, instrumentalists, songwriters, and other contributors** document their contributions to a creative work and determine an appropriate percentage split.

The idea behind the project is simple:

> **Every contribution should be documented, and every documented contribution should have a clear place in the final split.**

---

## 🎯 The Problem

Music projects can involve multiple contributors.

An artist may contribute vocals and lyrics.

A producer may contribute production and arrangement.

An instrumentalist may contribute instrumental performances.

A songwriter may contribute lyrics or composition.

Without properly documenting these contributions, disagreements can arise later around:

* Publishing
* Songwriting credits
* Ownership
* Royalty percentages
* Contributor recognition
* Registration of creative works

The Split Sheet Calculator was designed to make the process more structured.

---

## 💡 How It Works

The tool allows contributors to identify the different roles and contributions involved in a creative work.

The general workflow is:

```text id="n3l8qz"
Creative Work
     ↓
List Contributors
     ↓
Identify Contributions
     ↓
Assign Contribution Values
     ↓
Calculate Total
     ↓
Determine Percentage Split
     ↓
Document the Split
```

The result provides a clearer basis for determining each contributor's share.

## 📊 Contribution-Based Splitting

Rather than simply dividing ownership equally, the concept behind the application is to **document what each contributor actually did**.

For example, a project could contain contributions relating to:

* Lyrics
* Melody
* Composition
* Production
* Arrangement
* Instrumentation
* Performance
* Other agreed creative contributions

Each contribution can then contribute toward the final calculation.

The calculator uses those inputs to help establish the percentage attributable to each contributor.
